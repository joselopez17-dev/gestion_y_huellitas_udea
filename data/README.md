# Archivos de datos

Esta carpeta está destinada a los cuatro archivos planos de almacenamiento:

- `Peticion.txt`
- `Queja.txt`
- `Reclamo.txt`
- `Sugerencia.txt`

Cada archivo guardará exclusivamente registros de su tipo de solicitud y mantendrá un consecutivo independiente. Los archivos definitivos deberán ser creados y gestionados por el módulo de persistencia del programa. No se deben incluir datos personales reales en el repositorio.
